# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x.x   | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

**Do NOT open a public GitHub issue for security vulnerabilities.**

Please report security vulnerabilities responsibly via one of these channels:

1. **Email:** security@electronicstore.com  
2. **GitHub Security Advisories:** Use the "Report a vulnerability" button on the Security tab of this repository.

### What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact assessment
- Suggested fix (if you have one)

### Response Timeline

| Stage | Timeframe |
|-------|-----------|
| Acknowledgement | Within 24 hours |
| Initial assessment | Within 72 hours |
| Fix development | Within 14 days (critical), 30 days (high) |
| Public disclosure | After fix is deployed + 7 day grace period |

### Safe Harbor

We will not pursue legal action against researchers who:
- Report vulnerabilities in good faith
- Do not exploit vulnerabilities beyond proof-of-concept
- Do not access or modify user data
- Do not degrade service availability
- Disclose to us before public disclosure

## Security Practices

This project follows:
- OWASP Top 10 mitigations
- NIST Cybersecurity Framework
- Dependency vulnerability scanning via Dependabot
- Secret scanning via GitHub Advanced Security
- Regular penetration testing (quarterly)
